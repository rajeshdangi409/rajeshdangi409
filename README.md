<details>
<summary><b>⚡ Key Engineering Decisions (click to expand)</b></summary>

<br/>

**🔐 No static AWS keys anywhere**
Jenkins EC2 authenticates via an IAM instance profile — credentials are never stored as env variables or files.

**🔒 Private EKS worker nodes**
All EKS node groups run in private subnets with zero public IP assignment. External traffic routes through NAT Gateway only.

**🔄 CI and CD fully decoupled**
Jenkins handles build + push. FluxCD handles deploy. They communicate only via a git commit to the config repo — true GitOps. Separate repos also prevent webhook loops.

**✅ Idempotent Ansible roles**
Every role verifies the tool is already installed before attempting install. Handlers only fire on actual config change — safe to re-run anytime.

**🛡️ Image vulnerability scanning**
Trivy is installed via the `aws-tools` Ansible role and scans Docker images before ECR push.

**🚪 Manual approval gates**
Both the create and destroy Jenkins pipelines require human approval before Terraform apply/destroy runs — prevents accidental infra changes.

</details>
